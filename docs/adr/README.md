# Registro de decisiones de arquitectura (ADR)

Cada archivo documenta una decisión técnica relevante: el contexto, las opciones evaluadas, la
decisión y sus consecuencias. Las decisiones no se editan después de aceptadas; si cambian, se crea
un ADR nuevo que reemplaza al anterior.

| ADR | Decisión | Estado |
| --- | --- | --- |
| [0001](0001-eleccion-del-dataset.md) | Elección del dataset | Aceptada |
| [0002](0002-modelos-y-metricas.md) | Modelos candidatos y métricas de decisión | Aceptada |

Para una decisión nueva, copia [`plantilla.md`](plantilla.md) con el siguiente número.
