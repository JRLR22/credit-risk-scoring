- Paquete `credit_risk` con configuración por variables de entorno y logging.

- Integración continua con lint, tipos, pruebas, auditoría de dependencias y búsqueda de secretos.
- Dependabot para dependencias de Python y de GitHub Actions.
- Requisitos, criterios de éxito y alcance del proyecto.
- Arquitectura, diseño de la API y estructura del repositorio.
- ADR 0001 (dataset) y ADR 0002 (modelos y métricas).
- Estándares de desarrollo, plan de trabajo y política de seguridad.
- Plantillas de issues y pull requests.
